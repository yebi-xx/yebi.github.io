# 一期一會 · 瓷右企划产出归档

## 本地预览
解压后双击 index.html 即可（数据内联，离线可用）。

## GitHub Pages 上线（5 分钟）
1. 注册/登录 github.com
2. 新建仓库，名称：你的用户名.github.io
3. 上传本目录下所有文件（index.html / app.js / data.js / style.css / assets/）
4. 访问 https://你的用户名.github.io

## 站点结构
- 首页：复古电脑桌面（可拖拽窗口）
- 点击活动：档案袋解线过渡动画
- 内页：打孔档案卡（7 期 × 297 条产出 × 155 位老师）
